# 多鸟全图与逐只鸟种标注（r14）

同一画面检测到两个及以上鸟体时，缩略图和高清预览默认保留完整画面。虚线框使用完整解码画面的归一化坐标，随缩放、拖动和窗口尺寸同步。原片始终不裁切、不改写。

1. 点击虚线框或右侧鸟体编号，放大到这只鸟。右侧上方显示该鸟的候选及汉字/拼音搜索。
2. 点选鸟种只保存当前鸟体；也可标为暂不确定、此框不是鸟，或清除此鸟确认。
3. 点“返回全图 · 显示全部鸟种”“适应窗口”，或缩小至适应倍率，回到全图并列显示各鸟种。候选附有“候选”提示，不冒充人工确认。
4. 已确认的各鸟种都可参与鸟种筛选、鸟种计数和 CSV 输出；同张同种只计一次。之前的整图鸟种确认不被覆盖。原有整图复核状态仍独立于逐只标注；按鸟种筛选可找到逐只确认的鸟种。

照片级保留/待剔除、星级、隐藏、移动和综合质量分仍属于整张照片，不是单只鸟的处置或独立质量分。多鸟不纳入单一鸟种连续分组。标注存放在独立数据库 meta 表，数据库备份保留完整逐只记录；原有鸟种复核 JSON 仍只导出旧整图人工记录，不能替代数据库备份。

## 已扫描照片

旧记录若已含多个检测框，可以补生成整图高清预览，再手动逐只标注。旧缓存若只含主体裁切，界面不在它上面错画全图坐标框，也不会自动读取 RAW；需点击“生成此图高清预览”。如果还要独立模型候选，手选照片所在目录，开启重新扫描并核对清单。升级不自动重扫或移动。

检测器只找到一只时保持原单鸟行为，不能保证画面真的只有一只。暂未增加手绘新增鸟体或逐只调整检测框；漏检时仍需核对全图。旧手动裁切参数保持存储，多鸟工作台优先展示全图，不删除旧参数。

## 计算与存储

复用现有检测器、BioCLIP、单次原片解码和 CPU 模型，不增加容器、依赖或权重。多鸟每只新增一次分类，串行处理；为控制密集鸟群耗时，每张最多对前 16 个检测框生成独立候选，其他框仍显示并可人工搜索标注。检测框去重仍有误检风险。

仅存一份全图高清预览及其自动调整对照，不复制每只鸟的原片。点击放大使用浏览器已有预览，不读取 RAW；这是数字放大，不增加预览真实细节，最高适应倍率 8 倍。高清预览仍遵守边长和缓存预算。

人工记录绑定原片指纹和鸟体锚点。同源重新检测时仅在唯一可靠空间对应下使用新候选，保留人工框与名称；对应不清则保留旧人工框并提示核对，不转给邻鸟。原片变化后旧标注不套用，新标注保存时保留有限来源历史。多窗口保存检查标注版本及检测快照，冲突需刷新。

## 验证

本机使用合成像素和元数据验证，浏览器演示中的甲鸟、乙鸟仅是几何图形标记。没有把真实照片作为开发助手视觉输入；真实多鸟检测准确率、NAS 增加的耗时及触屏手感待安装后验证。
