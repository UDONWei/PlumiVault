# r15 空闲与原像素裁切缓存

无任务时网页立即停止定时任务查询；有任务但页面隐藏或两分钟未操作也暂停轮询。操作页面或手动刷新会重新查询。任务线程无任务时阻塞等待，识别子进程任务结束释放；没有后台扫描、预读原片或定时缓存清理。用户已启动的扫描不会因为鼠标不动而自动停止，需要主动暂停任务。

常驻服务仍监听请求、做健康检查；Tailscale 的保活独立存在。这不等于读取照片，但不能承诺整台 NAS 零活动。若要完全停止本应用，在确认无任务后可停止 app 容器，网页会暂时不可用；重新启动后恢复访问。不要在扫描/评分或原片整理进行中强行停止。

扫描时复用已解码、未自动增强的图像，按主体框截取原始像素，保存无损 PNG，不缩小、不用 JPEG 限额降质。多鸟缓存前 16 个框，默认整图仍用轻量预览；选中鸟后点“原像素裁切”读取对应缓存。无可靠主体时不自动缓存整张巨幅图片。原像素指解码后 RGB 像素和尺寸，不是 RAW 原始传感器数据。

轻量高清预览仍保留，用于快速切图；“原像素裁切”按需加载，无自动色调与降噪，适合核对细节。点击“适应窗口”或“返回全图”返回普通预览。像素多的裁切文件仍可能较大，外网加载速度受网络影响，数字放大不会创造细节。

缓存为 data/native-previews.sqlite3，内容预算 2 GiB，单张 256 MiB，只在生成新缓存时淘汰最早生成的内容，无空闲整理线程。它是可丢弃派生数据，不写入原片目录，不复制 ARW，不加入图库数据库备份。读取缓存不解码原片；缓存缺失提示重新扫描，不暗中回退读取 RAW。

已有照片不会自动批量生成。手选目录并开启重新扫描，只确认所需照片后生成。人工鸟种、星级、标记保持。新版不增加依赖、模型或容器。实际 NAS 空闲占用和与其他应用读取竞争的原因，需要现场进程/占用数据验证，不能从本机合成测试推断。
