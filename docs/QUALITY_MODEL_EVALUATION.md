# 质量模型：持续验证

r13 经维护者明确选择，已接入鸟眼细节、BioCLIP 遮挡/姿态描述匹配和组内备选参考。它们仍未校准，不宣称可靠的合焦判断、专门遮挡或审美模型。方法与上线边界见 AI_QUALITY.md。

tools/evaluate_bird_eye.py 是独立实验入口，可对使用者提供的本地清单进行数值评估。运行前须自行核对模型许可、校验权重、约束只读输入及输出目录。它不被生产评分调用；仓库没有实验权重、私人照片、裁切或结果报告。

后续仍需人工核对眼部定位，补充小鸟、遮挡、侧脸、运动模糊等场景，比较参考分和人工判断，报告误检、耗时与资源占用。不得将实验落点或未校准得分当成准确率。工作台纠正会保存当时模型输出，便于固定版本对比；独立验证集须按连续组隔离训练与验收，不能用同组近似照片制造准确率提升。

工作台现可直接收集独立验证组与人工清晰度、偏好标注，操作见 VALIDATION_SAMPLES.md。它只导出验证清单，不运行实验或把人工标签用于生产评分。公开文档不包含用户真实照片的复核内容。
