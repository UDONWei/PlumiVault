# 专门质量模型：实验状态

现有生产技术分估算主体清晰度与曝光，不具备经过验证的鸟眼对焦、遮挡或姿态审美能力。组内高分备选的专门模型方案尚未上线。

tools/evaluate_bird_eye.py 是独立实验入口，可对使用者提供的本地清单进行数值评估。运行前须自行核对模型许可、校验权重、约束只读输入及输出目录。它不被生产评分调用；仓库没有实验权重、私人照片、裁切或结果报告。

上线前需人工核对眼部定位，测试小鸟、遮挡、侧脸、运动模糊等场景，比较技术分和人工判断，报告误检、耗时与资源占用。不得将实验落点或未校准得分当成准确率。只有方案验证并由维护者确认后才能接入组内备选推荐。

工作台现可直接收集独立验证组与人工清晰度、偏好标注，操作见 VALIDATION_SAMPLES.md。它只导出验证清单，不运行实验或把人工标签用于生产评分。公开文档不包含用户真实照片的复核内容。
