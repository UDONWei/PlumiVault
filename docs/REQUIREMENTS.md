# 需求与边界

r12 可由用户明确选择将图库、网关与已启用的整理进程合并为一个应用容器，Tailscale 独立。需 Linux/amd64、Landlock ABI >= 6 及 seccomp，必须通过合成写保护预检；不满足则保留分容器部署，不降低保护要求。详见 COMPACT_DEPLOYMENT.md。

主要目标为 Linux/amd64 NAS、16GB 运行内存、数千至上万张照片，默认 CPU 串行推理。照片按拍摄日期分层存放，支持递归目录和 Sony A7R IV 压缩 ARW，兼容常见普通图片。

具备手选扫描目录、增量预览、鸟种候选、中文/拼音搜索、人工修正、元数据背景辅助、筛选与初筛标记、有限缩略图、任务进度和数据库备份。重新识别保留人工选择，处理失败只影响对应文件。

默认原片只读；所有数据库、缓存和日志存放在独立目录。正常推理离线，照片不得上传外部识别服务或作为开发助手视觉输入。整理功能单独启用，用户预览确认后可恢复移动，禁止永久删除和跨盘复制。

当前质量评分仅描述可测量的主体清晰度、曝光等技术特征；鸟眼、遮挡和姿态模型需要独立方案验证及人工复核后再接入。默认不自动标记或移走低分图片。
