# 使用说明

1. 登录 HTTPS 网关，在“扫描任务与拍摄背景”中手选目录，按需填写地区和日期。目录可排序并查看已扫描状态。
2. 先检查变更：核对新增、更新、待重试的编号和路径，再勾选确认。未变化的已处理照片跳过；不限张数仅作用于已选范围。
3. 在初筛工作台按目录、鸟种、标记、星级或参考分筛选。右侧显示鸟种候选和技术问题，人工确认独立保存。
4. 鼠标滚轮横向浏览缩略图；Ctrl 多选，Shift 选择范围。可批量标记和评星。连续同种组可展开或收拢，跨页仍按分页显示，收拢的成员不会被暗中加入批量选择。
5. 隐藏用于暂时排除不相关图片，既不删除也不移动；切换隐藏状态筛选可以找回并恢复。
6. 打开原图预览后可缩放和调整主体框。自动框是起点，手动框保存后用于裁切回显。亮度等调整只作用于内存处理，重新识别不覆盖人工鸟种、标记和星级。
7. 质量分只供排序参考，不能据此自动断定鸟眼对焦或姿态美观。虚焦、过曝等提示仍需人工复核。
8. 整理服务默认关闭。单独启用后，待删除标记、移动清单预览和最终确认缺一不可。新暂存路径保留照片根内相对路径，例如“未处理/日期目录/a.ARW”移至“待删除/日期目录/a.ARW”。同名冲突拒绝覆盖，历史暂存记录仍可恢复，不自动清空。

数据库备份和最近任务验证报告在更多设置中下载。备份含私人路径及标注，请留在私有存储。原图预览首次读取 RAW 可能较慢，关闭后短时间内可复用浏览器有限缓存，刷新或离开页面会清理。

## 高清主体预览

工作台默认显示自动调整的高清主体；“原图”切换同一裁切的未调整版本，“整张原图”保留独立入口。旧照片点击“生成此图高清预览”，或勾选后“补生成勾选图高清预览”。不会自动解码全库，也不修改人工色调、评分或原片。详细限制、缓存与验收见 [高清预览](HD_PREVIEWS.md)。

主图可滚轮缩放、左键拖动、双击恢复适应；触屏支持双指缩放。新增轻度降噪仅在“自动调整”预览中生效，已有预览需主动补生成，详见 [r11 高清预览说明](HD_PREVIEWS.md)。
