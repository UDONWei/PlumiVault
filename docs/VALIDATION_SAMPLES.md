# 在初筛工作台选择验证样片

此功能收集人工判断，不调用质量模型，不改变生产评分、鸟种、星级、保留标记、隐藏状态或原片位置。只在独立图库数据库保存一份当前验证批次，数据库备份包含这些标注；无需增加照片目录权限。批次最多 30 张，建议 3 组共 12～24 张。

## 选择与标注

1. 在初筛工作台选拍摄目录，尽量清除分数排序及会排除中间帧的筛选。用“展开组”查看自动连续组，也可用 Ctrl/Shift 自行选择同一目录的一段照片。
2. “勾选本页组”明确选中该组在当前页和筛选中的成员，并展开。跨页或被条件排除的成员不会加入，提示会显示本组总张数与实际勾选张数。每个验证组需 2 张以上，同一照片或相同内容不能重复加入不同组。
3. 展开上方“验证样片 · 清晰度与组内偏好”，点“勾选图建立验证组”。可修改组名；用途先留“待定”，确定验证方案后按整组分为调试组和独立验证组。
4. 点“在工作台查看本组”可集中浏览组内照片，不受当前目录筛选或分页限制。右侧“验证标注”中选择清晰、疑似虚焦、运动模糊、两者都有或原因不确定，再选择“最想保留”或“普通／非首选”。允许多张并列首选。选项立即保存；备注需点“保存验证备注”。
5. 相同清晰度判断可以勾选后批量应用，所选照片必须全部属于当前验证组。未标注与“普通”分开保存，不能把未核对当成负例。
6. 点“导出全部验证组 JSON”，获得 plumivault-quality-validation.json。换目录添加的组仍包含在本批中；导出不只包含当前页。未标完也可导出草稿，页面会提示未完成张数。

请先使用编辑器的“原始像素”查看眼睛与头部，结合整图判断，不凭缩略图判定虚焦。清晰度验证以原色原片为准；暂时调亮仅作辅助观察。全局 P/X 和星级快捷键仍用于日常初筛，不会替代验证标签。

刷新浏览器后，打开“验证样片”或右侧“打开验证样片”即可加载保存的批次。“移除该验证组”只清除这组验证记录，不删图、不移动；开始新一轮前先导出已完成批次。

## 导出内容与一致性

导出仅含组编号、组名、整组用途、照片编号、入口编号与路径、相对路径、索引 SHA-256/大小/修改时间、主体框、当时编辑参数、人工清晰度、偏好与备注。它不包含照片、缩略图或模型文件，但包含私人路径，请私下保管，不能上传公开 GitHub。

建立组时比较工作台照片指纹和编辑版本。加入后，索引内容、原片状态、授权范围或框选改变会阻止继续标注/导出；移除该组后重新加入并复核，不静默套用旧判断。多页面同时编辑采用版本检查，冲突后点“重新加载验证批次”。

导出只查询索引，不重新读取或计算原片哈希。磁盘上未反映到索引的变化，必须在实际实验开始前重新核对 SHA-256；既有离线眼部实验会核对文件指纹。本功能不自动启动该实验。

导出 subject_box 使用保存的手动框，未手动编辑时使用索引中的自动主体框，否则整图。亮度/对比度等作为 saved_recipe 记录以便追溯；本轮 evaluation_tone 固定 original_unadjusted，不把调亮后的图冒充原色质量样本。NAS 导出的 path 可能是容器内 /photos 路径，在电脑实验时按 root_id 和 relative_path 映射到现有只读共享即可，无需重新整理文件名或复制照片。

自动连续分组只是辅助，仍需核对同鸟同场景，避免把近似连拍拆到调试与独立验证两边。验证通过并由用户确认前，不启用自动组内优选或新评分模型。
